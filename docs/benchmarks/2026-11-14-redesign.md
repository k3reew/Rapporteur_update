# Проверка переработки «Репортёра», 14 ноября 2026

Исходное рабочее состояние сохранено в commit `7936205be873de5664840fd05a27d42f5d99b150` (`codex/redesign-baseline`). Реализация — отдельная ветка `codex/workflow-redesign`. Веса повторно не скачивались. До изменений `make check`: 248 Python- и 14 frontend-тестов.

## Подтверждённые проверки

- Полное совпадение OpenAPI до/после разделения маршрутов: 25 адресов, те же схемы, коды и форматы. Префикс `/api/v1` сохранён.
- Чтение SQLite доступно при занятом писателе, read-соединение запрещает запись. Создание конференции фиксируется до отправки HTTP-ответа; пойманный в реальном запуске ответ до COMMIT воспроизведён тестом и исправлен.
- Frontend: совместимость `processing`, следующий доклад, конфликт версий, разрешения массовой проверки, границы записи, частичный запуск после подтверждения, частичная загрузка, поздние ответы, версия черновика рекомендации, выбор докладов справки, темы.
- Старая вымышленная установка: ручные привязки, готовые сводки, разбиение записи на два доклада, ранее выпущенная справка. Старые DOCX/Markdown/PDF скачиваются с исходными SHA-256 (`tests/test_upgrade.py`).
- Реальный HTTP-путь на чистом локальном хранилище: текст выступления → подготовка → подтверждение → факты/цитаты/сводка → проверка → рекомендации по положению → DOCX, Markdown, PDF. В DOCX проверены автор и название отдела; PDF имеет корректную сигнатуру.
- Общая 50-секундная запись → Whisper → два доклада → две сводки → подтверждение обоих.
- Impeccable detector для `frontend/src`: пустой список нарушений. Новых frontend-зависимостей, облачных шрифтов и CDN нет.

## Локальное оборудование и модели

Одна NVIDIA GeForce RTX 2060 6 ГБ; Qwen3.5:4b Q4_K_M в Ollama, контекст 8192, без рассуждения. Whisper large-v3 использован на CPU/int8, 4 потока. Локальные лимиты и ASR/профиль переопределялись отдельным Compose-файлом; серверные настройки двух независимых GPU в поставке сохранены. Тесты Python используют предсказуемые ответы ScriptedClient; реальные запросы к моделям проверены отдельно.

Полный комплект включает серверную Qwen3.5:27b, небольшую Qwen3.5:4b для локальной диагностики, Whisper large-v3, три образа и файлы запуска. Основной серверный профиль остаётся `server` с 27B.

Основное действие материалов на 1366×768 находится в пределах экрана (нижняя граница 721px). Сворачивание ручного редактора и отмена перехода сохраняют черновик.

## Решения и поставка

Сохранены схема БД, версии зависимостей и существующие веса: структурный рефакторинг не требует новой миграции или замены моделей. Это сохраняет проверенную установку; оценка качества и скорости 27B остаётся серверной приёмкой. Проверенные локальные дубли весов объединены жёсткими ссылками для экономии диска; символических ссылок в комплекте нет. Обычное копирование даёт самостоятельные файлы.

Исходный код основного каталога не менялся: SHA-256 текущего `git diff --binary HEAD` совпал с сохранённым патчем (`b8d60eef4948b10db7091f2872ada92e5e7c8f58cf1dd3a64a74f6b6c0d91753`). Результат сохраняется в согласованной отдельной ветке `codex/workflow-redesign`; merge/push не выполнялись.

## Ограничения

Qwen 27B не запускалась на этой 6-ГБ карте. Скорость, качество и совместная работа на двух A100 40 ГБ проверяются на целевом сервере по `docs/acceptance.md`. Конференции организации и длительная нагрузка в локальную приёмку не входили. Реальное USB-копирование в этом обновлении не выполнялось. Встроенный браузер не применил команду нативного увеличения: проверена перекомпоновка при 683px, нативный zoom нужно допроверить на рабочем месте. Проверялся один локальный Docker Engine с чистым хранилищем приложения; ОС не переустанавливалась.
