# Обновление конвейера 0.2.1

17 ноября 2026. База f07a0d0, рабочая ветка codex/workflow-redesign.

## Изменения

- Объединение частичных фактов использует единый JSON-массив. Схема oneOf согласует наличие выводов с причиной их отсутствия. Резервная сводка выбирается с приоритетом допустимых связей и числа предложений.
- Допустимые метки перечисляются в JSON Schema запроса фактов. Модель и Python проверяют верхние границы массивов, длины факта и цитат.
- Факты повторно сверяются по исходному контексту. Сводка получает цитаты и контекст привязанных источников. Соседние ASR-сегменты помогают сохранять оговорки.
- Для больших источников передаются ограниченные окна около цитат с началом фрагмента. Канонический источник сохраняется целиком.
- Числа проверяются по привязанным источникам. Перед каждым исправительным запросом заново проверяется бюджет контекста.
- Смысловой критик проверяет каждое предложение. Замечания участвуют в трёх попытках формирования сводки. Непройденные проверки обозначаются needs_attention и требуют оператора.

## Совместимость

Публичные URL, HTTP-контракты и схема SQLite сохраняются. Сохранённые сводки и справки доступны. Новые алгоритмические версии фактов 2.4.0 и сводки 1.4.0 меняют ключ кэша. Активные профили используют промпты v2. Если установка подключает собственный profiles.yaml, для нового конвейера в нём следует указать prompt_version v2. Веса, порты, GPU и пути хранилища задаются существующим .env.

## Проверки

Полный набор 266 Python-тестов прошёл, включая тринадцать новых регрессий. Ruff и mypy прошли. Фронтенд сохраняет 27 проходящих тестов, проверки ESLint/TypeScript и production-сборку. Локальная среда использует Ryzen 5 3600, 15 GiB RAM и RTX 2060 6 GB.

На чистом хранилище и копии существующей установки проверены запуск образа, API и модели. Пять старых конференций открываются, выпущенные файлы сохранились побайтно. Реальный HTTP-сценарий с Qwen3.5 4B и Whisper large-v3 CPU int8 прошёл загрузку, подготовку, два доклада из синтетической записи, проверку, рекомендации и DOCX/Markdown/PDF за 155,915 с. Рабочий сервис обновлён с резервным копированием и запуском --no-build --pull never, состояние данных проверено после перезапуска.

В разработческом сравнении завершены все 37 назначенных генераций. Для 16 пар A/B подтверждённость составила 90/127 и 54/95 предложений, полное покрытие — 19/61 и 17/61 опорных тезисов. На пяти парах с презентацией и без неё показатели равны 22/30 против 13/28 и 9/25 против 4/25. Формальная разрешимость цитат B/C после фильтра равна единице. Исправленный конвейер продолжает требовать смысловой проверки оператором.

Генерация использовала summary 1.3.0. Последнее детерминированное исправление выбора резервной сводки 1.4.0 проверено воспроизведением всех 171 запросов B/C по сохранённым ответам без сети. Дополнительных вызовов модели нет, изменился один выбранный результат. Времена сравнения относятся к исходному генерационному проходу. ИИ-оценка неослеплённая, корпус использован при разработке. Независимая человеческая разметка и Qwen 27B на A100 ожидаются. Полные исходы, снимки и контрольные суммы включены в электронное приложение S1 к статье.
