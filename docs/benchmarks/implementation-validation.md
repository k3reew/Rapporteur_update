# Проверка запуска и офлайн-поставки

Проверка выполнена 13 ноября 2026 года на рабочей машине разработки.

## Окружение

- Ubuntu 26.04.1, 15 GiB RAM, одна RTX 2060 6 GiB, драйвер NVIDIA 595.99.02.
- Установлены Docker Engine 29.1.3, Compose 2.40.3, Buildx 0.30.1 и NVIDIA Container Toolkit 1.20.2. Docker включен в автозапуск.
- В контейнере Ollama выполнен `nvidia-smi`. Карта доступна через NVIDIA runtime.
- Образ приложения содержит Python 3.12.16, LibreOffice 25.2.3.2, FFmpeg 7.1.5 и Tesseract 5.5.0.

## Автоматические проверки

`make check` выполнен в Docker с отключенной сетью у проверочных контейнеров.

- **248 Python-тестов** прошли, включая разбор PPTX/Word, конвертацию в PDF, API, SQLite, миграцию, разбиение, массовую проверку, рекомендации и кэш порций.
- Ruff, проверка форматирования и mypy прошли для 78 исходных файлов и тестов.
- ESLint, TypeScript и **14 тестов интерфейса** прошли. Production-сборка Vite успешна.
- Добавлены проверки CPU/GPU-параметров ASR, загрузки пакетов с SHA-256, сборки диапазонов и повторного использования CUDA-колес.

## Настоящий инференс и HTTP

Локальная проверка использует Qwen3.5 4B Q4_K_M с контекстом 8192. Такой профиль выбран для имеющейся RTX 2060. В серверную поставку включается Qwen3.5 27B Q4_K_M.

Через HTTP API приложения проверен текстовый сценарий с настоящей Qwen.

1. Загружен текст выступления без заранее созданного доклада.
2. Модель предложила доклад, разбиение подтверждено через API.
3. Извлечены факты и сводка, выполнена ручная проверка через API.
4. Сохранены тема и автор, загружено положение отдела.
5. Рассчитана и подтверждена рекомендация с фактами доклада и пунктом положения.
6. Сформированы и скачаны DOCX, Markdown и PDF. Проверено наличие автора и отдела в содержимом DOCX. PDF отрисован, первая страница просмотрена.

В аудиосценарии Whisper large-v3 в режиме CPU/int8 распознала синтетическую запись длительностью 49.772 секунды. Qwen предложила два доклада, правильно указала авторов Alice Smith и Bob Jones и границу 26.4 секунды. Разбиение подтверждено через API, для обоих докладов сформированы и подтверждены сводки. В ходе проверки выявлена несовместимость faster-whisper 1.2.1 с PyAV 19. Закреплена PyAV 18.1.0, в сборку ASR добавлена проверка настоящего декодирования WAV без модели.

Исправленный образ ASR также проверен на RTX 2060 в режиме CUDA/float16 с отключенной сетью и отдельным пустым кэшем. Запись длительностью 18.494 секунды дала 5 сегментов с правильными именем автора и численным результатом 23%. Холодный запуск вместе с загрузкой модели занял 47.42 секунды, наблюдаемое потребление GPU было около 4 GiB.

В отдельном запросе Ollama Qwen получила изображение страницы справки и правильно прочитала полное имя автора. Ответ занял 11.9 секунды на этой машине.

Страница приложения и собранные JS/CSS возвращают HTTP 200. Внешнее TCP-подключение к `1.1.1.1:443` из приложения завершилось отказом/тайм-аутом при доступном интерфейсе через localhost. Порты Ollama и ASR на хост не публикуются.

## Офлайн-комплект

`make bundle` завершен. Каталог `bundle/` занимает 24.2 GiB и содержит три образа в `images.tar.gz`, Qwen3.5 27B с визуальным проектором, Whisper large-v3, конфигурацию, Makefile, проверку запуска и README. Проверочная Qwen 4B остается на машине разработки.

SHA-256 архива образов — `1ff648d9dcfe7d3dbe92ea60873e6d4e46876ba391bf53c9ff841b4416a11676`. Файл `SHA256SUMS` охватывает 20 файлов поставки, включая веса и инструкции.

Из каталога комплекта выполнен `make install`. Все контрольные суммы совпали, три образа загружены через `docker load --input images.tar.gz`, создан `.env` с путями к упакованным моделям.

В отдельном Compose-проекте выполнен запуск `up --no-build --pull never --wait`. Все три службы стали healthy. Через HTTP проверены интерфейс здоровья, доступность Ollama, единственная упакованная модель `qwen3.5:27b` и серверный профиль по умолчанию. Через HTTP ASR распознала отдельную запись из пустого кэша с упакованными весами на GPU/float16, правильно сохранив имя Alice Smith и результат 23%.

Для этого запуска применен локальный override с портом 18765, отдельным хранилищем и назначением ASR на единственную GPU 0. Qwen 27B в память этой карты не загружалась. Серверные файлы комплекта сохраняют назначение LLM на GPU 0 и ASR на GPU 1. Проверочный Compose-проект после завершения остановлен и удален. Локальная установка остается доступна на `http://127.0.0.1:18763` с Qwen 4B и ASR CPU/int8.

Docker Engine, Compose, драйвер NVIDIA, NVIDIA Container Toolkit и GNU make требуются на целевом сервере заранее. Установочные пакеты ОС подготавливаются под ее конкретный дистрибутив и версию.

## Границы проверки

Инференс Qwen 27B и Whisper на целевом сервере с двумя A100, распределение нагрузки между картами, расход VRAM и качество на реальных записях конференций требуют приемки на целевом сервере по [протоколу](../acceptance.md). Одна синтетическая запись и несколько контрольных запросов дают проверку работоспособности тракта. Оценку качества на материалах организации нужно выполнить отдельно.

Для команд Docker из пользовательского терминала после добавления в группу `docker` нужен новый вход в пользовательский сеанс.

## Повторная проверка готового комплекта 13 ноября 2026 года

Повторно проверены все 20 записей `SHA256SUMS`, включая архив и веса. Затем три образа повторно загружены из `images.tar.gz` через `docker load`. В отдельном проекте `rapporteur-recheck` с новым хранилищем выполнен запуск с `--no-build --pull never --wait`. Все службы стали healthy, `/health` вернул HTTP 200. Серверный профиль по умолчанию и упакованная Qwen 27B доступны через `/api/v1/system`.

После перезапуска всех трех контейнеров они снова стали healthy, HTTP доступен, кэш ASR сохранился. Проверочный проект остановлен после проверки.

Для местной машины применен отдельный override с единственной GPU 0, портом 18765 и ограничением памяти. В комплекте сохранены серверные настройки с разными GPU 0 и 1. Qwen 27B при этой проверке в память не загружалась.
