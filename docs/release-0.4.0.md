# «Репортёр» 0.4.0 в закрытом контуре

Комплект для Linux amd64 содержит приложение, vLLM, Whisper, веса и вымышленные материалы для приёмки. Серверный профиль использует Qwen3.5‑27B BF16 на двух A100 по 40 ГБ и Whisper small на CPU. vLLM и ASR доступны только внутри сети Compose.

## Установка

1. Подготовьте Docker Engine, Compose v2, GNU make, NVIDIA Container Toolkit и драйвер R580 или новее. Убедитесь, что обе карты свободны и отключён режим MIG для выбранных устройств. Проверьте свободное место на разделе Docker и на разделе хранилища.
2. Перенесите весь каталог комплекта вместе с `.env.example`, `SHA256SUMS` и каталогом `models`. Выполните `make install`. Команда сверит контрольные суммы, импортирует образы и создаст `.env` при его отсутствии.
3. В `.env` укажите UUID карт в `VLLM_GPU_ID_0` и `VLLM_GPU_ID_1`, свободный `WEB_PORT` и абсолютный `RAPPORTEUR_STORAGE` на файловой системе Linux. По умолчанию интерфейс слушает `127.0.0.1`. Для доступа оператора используйте согласованный интерфейс закрытой сети.
4. Выполните `make config`, `make doctor`, `make start`, `make ps`. Откройте «Настройки» и дождитесь готовности модели. Интерфейс и ранее созданные справки доступны, пока загружается Qwen.

Запускайте приложение одним экземпляром на данное хранилище. Веса подключаются на чтение. Штатный запуск использует `--no-build --pull never`. Файлы приложения, веса и образы можно подготовить заранее командами `make prepare-vllm BUNDLE=/путь` и `make bundle-vllm BUNDLE=/путь` на подключённой машине.

## Обновление и возврат

1. Остановите старый экземпляр и сделайте согласованную копию всего хранилища, включая SQLite, оригиналы и отчёты. Сохраните прежний комплект, `.env`, образы и каталоги моделей.
2. Запустите 0.4.0 с копией хранилища, отдельным `COMPOSE_PROJECT_NAME` и свободным портом. Проверьте открытие старых материалов, скачивание выпущенной справки и возобновление фонового задания. Миграция создаёт резервную копию SQLite перед повышением номера схемы, а полное восстановление опирается на копию каталога.
3. Выполните [серверную приёмку](acceptance-0.4.0.md) с отдельным пустым рабочим каталогом. После успешной приёмки переключите доступ оператора на новую установку.
4. Для возврата остановите 0.4.0. Запустите прежний комплект с его конфигурацией и сохранённым исходным каталогом. Работу, сделанную после переключения, сохраняйте отдельно для переноса по решению администратора.
