## Справочные сведения

### Конференции

Название, даты, место → проверка полей → карточка. Оператор создаёт, правит и подтверждает удаление.

Возможные ошибки и действия отражены в профильном руководстве. Нет ID — 404, неверные поля — 422.

| Связь | Реализация |
| --- | --- |
| Экран | Главная, карточка |
| API, сокращённые пути | `conferences GET/POST, conferences/{id} GET/PUT/DELETE` |
| Предметная область | `api/conferences.py` |
| Данные | `conferences` |
| Проверка | `tests/test_app.py` |

### Материалы

Файл или папка → определение формата, лимиты, SHA-256 → инвентарь. Оператор выбирает назначение.

Возможные ошибки и действия отражены в профильном руководстве. Дубликат 200, другой файл по занятому пути 409, тип 415, размер 413. Частичный успех сохраняется.

| Связь | Реализация |
| --- | --- |
| Экран | Материалы |
| API, сокращённые пути | `conferences/{id}/materials GET/POST, files/{id}/purpose PUT` |

| Данные | `files, blobs` |
| Проверка | `tests/test_multimodal.py, frontend/src/WorkflowPages.test.tsx` |
