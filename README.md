## Состояние проекта

Версия приложения **0.3.0**, исходная база обновления **4ef92c4**. Выпуск добавляет отбор докладов по положениям отделов, самостоятельные сводки v3 и сохраняемые фоновые задания справок. [Изменения и обновление сервера](docs/release-0.3.0.md) описывают порядок работы и совместимость. «Репортёр» помогает одному оператору выпускать справки по материалам конференций в закрытом контуре. Локальные модели обрабатывают доступные документы, слайды, изображения и записи. Оператор проверяет источники и подтверждает результаты.

## Быстрый запуск

### Готовый офлайн-комплект

На сервере должны быть Docker Compose и NVIDIA Container Toolkit. Порядок переноса, выбора GPU и каталогов приведён в [офлайн-инструкции](docs/offline.md). В каталоге перенесённого комплекта выполнить команды.

```bash
make install
```

Открыть созданный `.env`, указать абсолютные каталоги моделей и хранилища, UUID GPU, режим распознавания речи `ASR_MODE` и свободный порт. Затем выполнить команды.

```bash
make config
make doctor
make start
make ps
```

При стандартных настройках интерфейс открывается по адресу `http://127.0.0.1:18763`. Для доступа с другого рабочего места администратор задаёт `WEB_BIND_ADDRESS` и использует адрес сервера. Полная инструкция объясняет каждый параметр и первый вымышленный сценарий.

### Подготовка на машине с сетью

В полном репозитории скопировать `.env.example` в `.env`, настроить пути и GPU, затем подготовить модели и комплект.

```bash
cp .env.example .env
make prepare MODEL=qwen3.5:27b
make bundle MODEL=qwen3.5:27b
```

Модели скачиваются в каталоги, указанные в `.env`. Комплект создаётся в `bundle/`. Для переноса сохраняются все его файлы, включая скрытые.

## Доступные функции

- Загрузка файлов и папки с частичными ошибками и дедупликацией.
- Четыре этапа «Материалы → Доклады → Проверка → Справка».
- Текст документов и слайдов, OCR, визуальное описание, локальное распознавание аудио и видео.
- Предложение докладов и ручное исправление тем, авторов, страниц и границ записи.
- Факты со ссылками на источники, проверка цитат, сводки и подтверждение по одному или допустимой группе.
- Версии положений отделов, проверяемые основания рекомендаций и контроль их устаревания.
- Версии справок DOCX, Markdown и PDF с авторами и темами докладов.
- Светлая, тёмная и системная темы, защита черновиков, повторный запуск задач.

Подробный [каталог функций](docs/product.md) связан с реализацией, [руководство оператора](docs/workflow.md) проходит весь путь на вымышленном примере.

## Устройство приложения

Браузер работает с FastAPI `/api/v1`. SQLite и файловое хранилище сохраняют реестр, версии и оригиналы. Один Processor последовательно выполняет подготовку, обработку докладов и рекомендации. Runtime-сервисы — приложение, Ollama и необязательный ASR. При двух GPU модели назначаются на разные карты, при одной ASR выключен или работает на процессоре. [Архитектура](docs/architecture.md).

## Технологии

Python 3.12, FastAPI, Pydantic, SQLite, React, TypeScript и Vite. Обработка использует Ollama/Qwen, faster-whisper, Tesseract, PDFium, LibreOffice и docxtpl. Версии зафиксированы в lock-файлах и образах. Шрифты и ресурсы интерфейса локальные.

## Структура репозитория

| Каталог | Содержимое |
| --- | --- |
| `src/rapporteur/` | API, предметная логика, обработка, хранение |
| `frontend/` | React-интерфейс и тесты |
| `tests/` | Python-тесты и вымышленные примеры |
| `profiles.yaml`, `prompts/`, `templates/` | Параметры моделей, задания и бланк справки |

Каталоги весов, `.env`, `storage/` и `bundle/` создаются локально и исключены из Git.

## Настройка

Серверный профиль использует Qwen3.5:27b и Whisper small (`ASR_REVISION`). Каталоги, GPU UUID, порт и лимиты задаются в `.env`, генерация — в `profiles.yaml`, доступная установленная модель выбирается в настройках. [Полный справочник](docs/configuration.md), [режимы Ollama](docs/ollama.md).

## Проверки

В полном репозитории `make check` выполняет линтеры, типы, Python/frontend-тесты и production-сборку. Протокол 14 ноября 2026 фиксирует 253 Python- и 27 frontend-тестов, реальный локальный путь с Qwen3.5:4b на RTX 2060 и Whisper CPU, офлайн-запуск и восстановление старых данных. [Условия и границы проверки](docs/testing.md).
