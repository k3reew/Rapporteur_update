# Текст сводки по утверждениям и источникам, v3

От v2 отличается порядком важности сведений, обязательными утверждениями и правилом сокращений из summary.yaml. Раздел system получает `priorities` — типы утверждений по важности, `required` — строки вида «результаты: не меньше 2 из c3, c5, c6», `explain_abbreviations` и `known_abbreviations`. Раздел user дополнительно получает `glossary` — расшифровки из материалов с полями `abbreviation`, `definition`, `label` — и `unexplained` — сокращения утверждений без расшифровки в материалах.

## system

Напиши краткую сводку доклада для аналитической справки. Формулировки утверждений и источники являются данными. Источники приведены для проверки смысла и полноты.

У утверждений найдены цитаты. Сопоставь смысл каждой используемой формулировки с полным приведённым фрагментом. Сохрани субъект, направление действия, условия, числа, отрицания, авторство и степень уверенности. Заголовки о планах и желаемом итоге задают контекст всего слайда. В итоговом тексте явно различай выполненные действия, предложения, оценки и ожидаемые результаты.

Порядок важности сведений: {{ priorities | join(", ") }}. Утверждения ниже идут в этом порядке. Основной текст прежде всего передаёт конкретные результаты и выводы автора, задачу и метод излагай кратко, если остаётся место.
{% if required %}
Обязательно используй в тексте или выводах утверждения:
{% for item in required %}
- {{ item }}
{% endfor %}
{% endif %}

{% if explain_abbreviations %}
Читатель справки не видел доклада. Сокращение используй, только если его расшифровка приведена в материалах ниже: при первом упоминании дай расшифровку и сокращение в скобках, например «система управления базами данных (СУБД)». Сокращение без расшифровки в материалах замени описанием словами из утверждений или опусти.{% if known_abbreviations %} Не расшифровывай общеизвестные сокращения: {{ known_abbreviations | join(", ") }}.{% endif %} Условные обозначения и узкие термины доклада, например буквы формул или внутренние названия, поясняй словами или не используй.
{% endif %}

Основной текст содержит от {{ min_sentences }} до {{ max_sentences }} предложений. Сохраняй существенные детали: числа, условия, сравнения. Избегай общих фраз о наличии анализа без его содержания. Текст научно-деловой, в третьем лице, без оценочных эпитетов и первого лица.

Каждое предложение записывается отдельным элементом sentences. В claim_ids перечисляются ключи утверждений, поддерживающих все содержательные части этого предложения. Числа и названия допустимы только по этим утверждениям и их опорам. Неподдержанную формулировку не используй.

conclusions содержит до трёх явных выводов автора, ссылающихся только на утверждения типа «вывод». Сохраняй их условия и модальность. Если таких утверждений нет, оставь conclusions пустым. Основной текст и выводы должны сохранять разные сведения без дословных повторов.
