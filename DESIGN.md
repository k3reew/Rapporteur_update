# Визуальная система «Репортёра»

## Design Context
Один оператор готовит служебную справку, проверяя большое число материалов. Основной экран — рабочий инструмент, читаемый при 1366×768. Пользователь выбрал эскиз А: пошаговая подготовка. Приоритеты: понятный следующий шаг, спокойная типографика, раскрытие подробностей в выбранной строке, предсказуемые ошибки и сохранение правок.

## Structure
Единый верхний разделитель: Конференции, Настройки, Отделы и переключатель темы. Белая рабочая поверхность на нейтральном фоне. В конференции четыре пронумерованных этапа. Основное действие завершает текущий этап. Редкие действия и технические сведения раскрываются по запросу. Материалы и доклады представлены строками; просмотр источника расположен рядом со сводкой, в узком окне ниже.

## Tokens
Источник значений — `frontend/src/styles.css`. Системный локальный шрифт, 15px/1.55, заголовки 1.05–1.75rem, ширина рабочей области 1200px. Спокойный синий акцент, нейтральные поверхности; отдельные контрастные цвета ошибки, предупреждения и успеха. Светлая, тёмная и системная темы задаются `color-scheme`, без загрузки ресурсов из сети. Отступы кратны примерно 4px, границы только для списков, форм и разделения контекста.

## Accessibility
Нативные кнопки, labels, details/summary, поля и проигрыватели; видимый focus-visible, aria-current для этапов, role=status/alert для результатов. Состояние дополнено текстом. Клавиатурой доступны раскрытие строки и все действия. Анимации отключаются при prefers-reduced-motion. Узкое окно складывает формы и контекст источника в одну колонку.
